# grok-weekly

Kuro Hsu 的每週技術趨勢週報存檔（由 Grok Bot「科技趨勢專家」整理）。

## 發布流程（必守）

1. **調研**：官方來源 + **SNS／追蹤帳號訊號（必要）** + GitHub 等  
2. **審稿**：先在 Grok Bot 聊天交出草稿，經 Kuro 審過（必要時再走部落格編輯／說人話流程）  
3. **貼 Issue**：審稿通過後，才在本 repo 開一則 Issue（一週一則）

**不會**在未審稿前自動開 Issue。

## Issue 慣例

- 標題：`本週技術趨勢週報（YYYY-Www）`  
- 內文：結構化週報（本週焦點／分區／社群／覆蓋／下週可追／建議持續關注）  
- Label：`weekly`（可選）

## 時程

每週一上午（台北時間）產出草稿；貼 Issue 時間以審稿完成為準。
