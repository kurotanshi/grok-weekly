# grok-weekly

Kuro Hsu 的每週技術趨勢週報存檔（由 Grok Bot「科技趨勢專家」整理並自動貼 Issue）。

## 發布流程

1. **調研**：官方來源 + GitHub + **SNS／追蹤帳號訊號（必要）**  
2. **SNS 閘門**：必須爬到可驗證的社群貼文並寫進「社群」段落；爬不到就不發 Issue（會在聊天告知）  
3. **自動貼 Issue**：SNS 通過後直接開一則 Issue（一週一則），**不必**人工審稿

## Issue 慣例

- 標題：`本週技術趨勢週報（YYYY-Www）`  
- 內文：結構化週報（含社群 X／Threads）  
- Label：`weekly`

## 時程

每週一上午（台北時間）自動產出並在 SNS 通過後貼上。
